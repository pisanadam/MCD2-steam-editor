# Application icon

Generated with the built-in image_gen tool, with transparency. The original PNG is preserved; Pillow encodes it as a multi-resolution Windows ICO (16, 24, 32, 48, 64, 128 and 256 px). Both the executable resource and the desktop window use this ICO.

Final generation prompt:

> Use case: logo-brand. Asset type: Windows executable app icon for Dungeons II Forge, a local save editor for a blocky dungeon adventure game. Create one original square 1024x1024 icon: a bold block-shaped forge anvil with a short enchanted pixel sword and a small luminous green emerald inset. Style: crisp chunky voxel/pixel-art silhouette, polished game utility icon, dark charcoal forge, luminous emerald green and warm gold accents matching the editor. Centered compact composition, large readable shapes that remain clear at 16x16 and 32x32, generous empty margin. No text, no letters, no frame, no copied official game logo. Transparent background around the emblem. Deliver a single clean icon, no mockup sheet.
